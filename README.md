# Abdulrahman Khedr — Portfolio Website

A lightweight, responsive personal portfolio website for showcasing software, automation, embedded systems and robotics projects.

## Sections
- Hero / professional positioning
- Featured projects
- Technical skills
- Experience
- Education
- Contact

## Featured projects
- Graduation Planner & Academic Advising System
- AI E-commerce Automation & Product Intelligence
- Engineering Course File Manager
- Energix Communication Automation Suite

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
In this repository: **Settings → Pages → Deploy from a branch → main / root → Save**.

The site is intentionally static and dependency-light.
